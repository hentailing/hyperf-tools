# 关于缓存驱动
能在一定程度上解决缓存分组的问题(缓存命名空间)
- ## 注意事项
- 缓存的键名应该尽量只有`[\d\w_-]`,不要使用`.`作为键名,因为我用的`.`作为命名空间分隔符
- 文件缓存注意文件名长度限制
- Apcu是一个很不错的php扩展在通用的条件下个人觉得是最优本地进程共享内存缓存扩展
- 计数器使用的时候注意初始化的时机，技术能力有限无法实现原子性，我们可以明确地定义初始化时机避免，如进程启动的时候把所有需要计数的初始化
